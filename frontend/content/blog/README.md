# Как добавить статью в блог

Создайте файл `content/blog/название-статьи.mdx` (slug = имя файла) вида:

```mdx
---
title: "Заголовок статьи"
description: "Краткое описание для превью и SEO (og:description)."
date: "2026-08-30"
tags: ["152-ФЗ", "GDPR"]
---

Текст статьи в Markdown. Можно **жирный**, *курсив*, [ссылки](/pricing),
списки, > цитаты и заголовки `##`/`###`.
```

Дата — обязательно в кавычках (`"2026-08-30"`), иначе YAML распарсит её
как объект `Date`, а не строку.

Больше ничего делать не нужно — статья появится в `/blog`, на своей
странице `/blog/<slug>` и в `sitemap.xml` при следующей сборке.
Код трогать не нужно.
